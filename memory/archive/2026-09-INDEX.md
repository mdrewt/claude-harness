## Why

`docs/revision-2026-09/diagnosis.md` (Part 2, C12, "The harness has the disease too")
found that `memory/projects/` had grown to about 1,381 files and 200k lines, most of it
run exhaust. The bulk was per-slice plan and progress memos, gate ledgers, probe and
bite-proof scratch, backups and merge strays. Every future agent that listed or searched
the directory paid for that noise, and its volume hid the small set of files the loop
actually runs on. None of the removed files is read by a live tool. Tracked ones stay
recoverable from the tag, and untracked ones from the tarball.
