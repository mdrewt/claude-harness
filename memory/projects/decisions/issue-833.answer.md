There is a case that you have overlooked. If the friend set up the game server in the cloud with a static IP address and a correct port configuration, and the player wants to be able to join the server from a public computer that does not have the desktop client installed, then they would need to join using the browser client by navigating to the server's IP address.

This behavior should be allowed while maintaining security and other best practices.
