Parser (RAW file, line/cursor walker): (a) hoisted forms — every top-level `const <IDENT> = cldr({` … `})` (six UNQUOTED keys, single-quoted values, any whitespace) or `const <IDENT> = oneOther('one', 'other')` → forms map; any other shape after `= cldr(`/`= oneOther(` → PLURAL-FORMS-UNPARSEABLE. JSON (`<tag>.icu.json`): `{ "locale", "sourceLocale": "en", "generatedBy": "scripts/catalog-export.mjs", "messages": { "<key>": { "message", "description", "notes": [...], "params": [...], "translated": bool } } }`, keys in catalog order, `JSON.stringify(o, null, 2) + '\n'`, no timestamp. `params` (exporter-derived from the holes) is the arity contract the importer enforces; `translated` = no marker ⇒ true.

## 10. AMENDMENTS after the plan review (reviewer + red-team, 2026-09-21) — these OVERRIDE §1–§4 where they conflict
A1 (rt-B1) ICU quoting: quote each MAXIMAL RUN of special chars as ONE span — `'` + run with every `'` doubled + `'`. Specials: `{` `}` at top level; `{` `}` `#` inside a plural branch; `|` never. A `'` not adjacent to a special → `''`. (`{}`→`'{}'`, `{'}`→`'{''}'`, `x}{y`→`x'}{'y`, `l'{x}`→`l''{x}`.) Importer decoder is ICU4J-faithful, DOUBLE_OPTIONAL (rev-M1): `''`→`'`; `'` followed by a special (context-sensitive as above) opens a span that ends at the next LONE `'` (`''` inside = literal `'`, span stays open); a lone `'` followed by a non-special is a literal apostrophe; unterminated span → ICU-SYNTAX. The TEST carries its own ~15-line reference decoder as the independent oracle for RT-03/RT-09 (never the importer's).
A2 (rev-B1 / rt-B2) biome quote flip: the parser accepts `"…"` plain values (decode `\"` `\\` `\'` `\n` `\t`); the emitter picks biome's quote (double when the text has `'` and no `"`, else single). The I18N-29 property runs the REAL formatter: `J1 = export(parse(src))`, `T = biome-format(emit(import(J1)))` (one `client/node_modules/.bin/biome format --write` spawn over the mkdtemp files), `J2 = export(parse(T))`, `J1 === J2`. RT-02: `"it's"` is a GOOD fixture; RT-09: `it''s` → `"it's"` (double-quoted) → re-export `it''s`.
A3 (rt-B3) CONTROL-CHAR: importer rejects any code point < 0x20, 0x7F, U+2028, U+2029 in message / description / plural branches; rejects `${` in any message text (biome noTemplateCurlyInString + template injection) as ICU-UNSUPPORTED; `importLocale` RE-PARSES its own emitted text with `parseCatalogSource` and compares the model (keys, kinds, texts, params, plural forms, descriptions, translated) to the validated input BEFORE writing (EMIT-MISMATCH; write to `<out>.tmp` then rename).
A4 (rev-M3 / rt-M1) completion ratchet is GAP-ONLY: `--check` → REGRESSION when a baseline tag is missing live or `live.gap > base.gap`; STALE when `live.gap < base.gap` or a live tag is absent from the baseline; missing baseline file → BASELINE-MISSING; exit 1 on any non-OK; `total`/`translated` are informational only (never compared). The WRITER (`--completion`) refuses to write a per-tag gap larger than the committed baseline's (prints the REGRESSION line, exit 1, no override flag — the fix is to translate); new tags and shrunk gaps write normally.
