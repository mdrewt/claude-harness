uppercase) since `normaliseMediaPrelude` lowercases first (hp-bar:546) and the feature name is
always textually present regardless of polarity.

## Notes on fixture independence

- No two RED fixtures are satisfiable by the same single-token check: e1 (basic), e2 (polarity),
  e3 (stack position), e4 (comma), e5 (nesting throw), e6 (case), e13 (boolean form), e14 (`not`
  form) each require a DIFFERENT piece of `normaliseMediaPrelude`/`parseCssStyleRules` behaviour to
  be wired up correctly; collapsing any one clause of the intended implementation to a shortcut
  drops at least one of these while leaving the others green (this is deliberately mirrored on
  `guardPreludeIsEquivalent`'s own S9 teeth, hp-bar:594-598, which this reuses transitively).
- Every GOOD fixture (e7-e11, e16, f4, f5, f6b/c) is drawn from either the LIVE tree or a
  documented future-legitimate shape (S9's contrast tokens) — none is a strawman that a correct
  implementation could accidentally over-satisfy by being too strict in an unrelated way.
