4. AMBIGUITIES
  - "Names the kind as a whole word": letter case is unspecified. I match case-insensitively. This is lenient on the kind's own name (so "Local world" counts as naming local) and strict on the other kinds (a "Test" in a private reason fails).
  - The ConnectionOptions authIssuer and authClientId are optional (connection.ts:163-164), and connection.ts treats undefined as ''. The contract says `=== ''`, so the test pins '' and an implementation that omits the fields fails.
  - Out-of-range values include 'OFFICIAL' and ' official'. The spec makes any value outside TargetKind disabled, so a case-folding implementation fails by design.
