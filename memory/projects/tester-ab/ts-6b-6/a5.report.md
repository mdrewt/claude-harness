### 1. `a_tactical_win_that_levels_a_monster_up_recomputes_stats_heals_and_auto_evolves` (ts-6b-6.1)
Helper `level_up_win(fx, w, edge)` builds the scene: live_pair, u2 falls first (so only monster 11 earns),
`ready_ko`. Monster 11 is made a true level-5 monster of species 1: stats = `derive_stats(species 1 base, row IVs/EVs/nature, L5)`,
xp = `xp_for_level(6) - 1` (so any award >= 1 crosses level 6), current_hp = L5 max. Unit u1 is wounded to
`L5max / 2`; the anchor's side-A team[0].max_hp is set to the L5 max (this is `old_max_hp` that `credit_monster` receives,
since `bm.max_hp` comes from the anchor and `mirror_hp` only rewrites current_hp). The KO submit wins; the killer's award
is computed from the finished board with `on_unit_defeated` + `pay` (same oracle as the existing bt9_1 win test).
Preconditions asserted: row is L5/species 1/true L5 stats before; awards.len()==1 and xp>=1; the finished anchor carries
(pre_hp, L5max); level strictly rises; derived.hp > old max (growth positive) so the heal is visible; healed > pre_hp.

Scenario 1 (no edge, fresh fixture), expected values:
- (xp, level) == `after_gain(before.xp, award.xp)`
- six stat columns == `derive_stats(species 1 base, IVs, EVs, nature, new level)` (and != the pre-win columns)
- current_hp == `level_up_healed_hp(pre_hp, old_max_hp, derived.hp)` (> pre_hp)
- species still 1; essence pool of the victim's affinity > 0 (so scenario 2 can show it spent)
- monster_pub mirrors level/xp/current_hp/species and the six stats.

Scenario 2 (edge seeded: all species rows, pending_evolution_notice writable, one EvolutionPathRow
path_id 1, from species 1 -> to species 2, min_level 6, no essence, no tier gates; fresh fixture):
- precondition: row level 5 < 6 before the win, so the edge is not eligible beforehand; after the win level >= 6
- species_id == 2
- six stats == `derive_stats(species 2 base, IVs, EVs, nature, new level)`, precondition that this differs from the species-1 derive
- current_hp == `level_up_healed_hp(pre_hp, old_max, derive(species1).hp).min(derive(species2).hp)` (evolve clamps, does not heal)
- all eight essence pools == 0 (evolve spends them)
- monster_pub species 2, tier == species 2 content tier, six stats evolved
- pending_evolution_notice: one row for owner a() with exactly one entry {monster 11, from 1, to 2, evolved_at_ms == T0 + 25_000}

Breaks it catches: stat_* writes dropped (scenario 1 stats; scenario 2 differs too); `current_hp = level_up_healed_hp` dropped
(scenario 1 HP, growth positive); `check_and_evolve(ctx, mid)` dropped (scenario 2 species/stats/pools/notice).

  I am fairly but not fully certain of this exact Skittish plan (derived by hand, `stride_points(1,30)=2` read from the file's header doc, not from code).
  If it is off, only the PRECONDITION assertion fails; fallback per the brief is "not equal to Territorial and starts with a Move".
