== Ambiguities in the contract ==
- Same-frame hand-over: I assume the frame whose tick() drains the last beat also shows the results panel (the brief says
  "a frame past the total shows the results panel"). If the builder re-runs the refresh one frame later, the required test
  and the three-key test fail by one frame.
- When the outcome edge (outcomeShownAtMs) restarts: the stack's syncStack sets it at the first sync AFTER the panel shows.
  The tests are written to be robust to the edge starting at the show frame or at the next frame/key (an extra frame is run
  after the show; the A-grace probes use the +50 ms margin). They are NOT robust to an edge that starts later than the next
  frame.
- While waiting, the tests assert the stack stays ['world','battleView'] (the brief says "the outcome frame is still on the
  stack"); if the builder withholds that frame during the wait, those assertions are wrong from the spec and need revising.
- B/A/Start "consumed" is checked by the effect (frames unchanged, shell stops playing), not by defaultPrevented.
- Shell speech: an own PlanHalted before any vm was rendered is asserted NOT spoken (no vm: no unit is known to be own).
  skip() is asserted not to drop queued announcement lines (a KO skipped past is still spoken at the next tick).
- Live-region wiring test spaces its checks > 500 ms apart because LiveRegion coalesces last-write-wins; the first-sighting
  own turn cannot be asserted through #a11y-live (the overlay-open edge announced after tick() in the same frame clobbers
  it), so that rule is carried by the shell-level test only.
